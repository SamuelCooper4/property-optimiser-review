Design choices and supersession

The 2 November owner brief supersedes earlier fixed-term, single-view, deferred-contribution and “no R4” design restrictions for this isolated experiment only. Legacy engine semantics and frozen releases remain unchanged. Main measure includes the common house value, continuing R3-v12: house + cash + investments − mortgage debt. This supersedes the older design-language instruction to omit common house value from the main chart; explicit difference charts identify their baseline.

Provisional default: compact connected house/money summary, deposit–term map with adjacent deposit curve, and timeline with a selected-date breakdown. Inputs live at right; mobile uses a dedicated input drawer. The calculated best, inspected plan and pin have distinct labels and markers. Gallery alternatives test direct annotation vs linked detail; outcome heatmap vs near-best region; timeline breakdown vs component small multiples; overlaid stress paths vs aligned path panels; connected compact diagram vs spacious money objects. No smoothed contour interpolates unsupported cells.

Research supports the provisional rendering decision: retain hand-authored SVG and React for exact points, responsive labels, native HTML controls/tables and minimal dependencies. New chart code consumes one provider contract. Optional 3D is a controllable projected wire surface over returned points with a linked 2D slice; it is never required to understand the result.

All live dashboard calculations are category 2: coherent isolated exploratory model. No tile borrows legacy M6 probability bands. Statutory LISA checks, tax, inflation, investment fees, repeated refinancing and production suitability remain unavailable. Restricted purchase funds are a separate source already confirmed usable by the user, not savings counted twice or automatically qualified LISA.

Financial contract

Version r4-exploratory-v1, assumptions effective 2026-11-02. Fixed50 Decimal growth/annuity context independent of caller, with exact additive monetary sums to preserve cancellation and zero-growth ties; monthly mortgage rate annual nominal/12; cash/investment monthly factors from annual-effective assumptions. End-of-month order: investment/cash growth and named market shock, mortgage interest and required payment, funded overpayment, remaining monthly funding invested. Reserve is not consumed to cover shortfalls. A shortfall marks the plan ineligible from that month; later conditional debt path is labelled unfunded and excluded from optimisation. No interest saving is added to wealth a second time.

Costs and upfront product fee use unrestricted cash, then unrestricted deposit, reserve and opening investment; committed funds go only to deposit. Search includes evenly spaced penny deposits, exact configured LTV thresholds with adjacent pennies, and capital endpoints. Precision is disclosed; no exact global optimum claim. Whole-year term limits are separate from comparison month and fixed period. Results retain full inputs, versions, source ledger, exclusions and every monthly value needed for numerical equivalents.

Interaction contract

Draft inputs never mutate displayed calculation assumptions. Calculate sets pending, then commits one returned snapshot; failure retains draft and last valid snapshot with explicit stale status. A completed result selects its authoritative best; clicking a chart commits inspection only. Hover previews locally without changing selection. Pin stores another plan within the same calculation; recalculation resets the pin. Comparison date selects precomputed best-by-year and eligibility; trajectory cursor only inspects time. Stress modules hold plan identities fixed until a separate explicit reoptimise action.

Only tile IDs/order persist in localStorage. Inputs are held in memory; no analytics. Native buttons, selects/ranges, focus rings, numerical tables and reduced-motion states accompany graphics. Mobile complex tiles can expand into a full-width view.
